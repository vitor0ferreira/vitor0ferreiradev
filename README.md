## 🏛️ Sobre o Projeto

**The Digital Archive** é um portfólio de engenharia e arquivo técnico inspirado no conceito **Swiss Minimalist & Technical Editorial / Brutalist Dark Archive**. 

O projeto trata o trabalho de desenvolvimento e arquitetura de software com a reverência de um museu arquitetônico, priorizando integridade estrutural, contraste marcante, tipografia editorial e marginalia técnica em tempo real.

---

## ✨ Funcionalidades Principais

* **Bilingual Engine (i18n)**: Alternância instantânea e persistente entre **Português (PT-BR)** (padrão) e **English (EN-US)** em todas as telas e fichas técnicas.
* **Barra de Telemetria ao Vivo**:
  * Relógio de sistema em tempo real (`SYS_TIME()`).
  * Coordenadas GPS reais (`19.7472° S, 47.9392° W [Uberaba, MG]`).
  * Medidor dinâmico de rolagem da página (`% ROLAGEM`).
  * Indicador de pulso de disponibilidade operacional (`DISPONÍVEL`).
* **Catálogo de Engenharia (`01 // ARQUIVO`)**:
  * Filtragem instantânea por categorias (`TODOS`, `FULL-STACK & SISTEMAS`, `IA & DEEP LEARNING`, `TEMPO REAL & WEBSOCKETS`, `LANDING PAGES & UI/UX`).
  * Fichas de caso estruturadas no padrão **Desafio Técnico &rarr; Arquitetura & Solução &rarr; Impacto & Performance**.
  * Enquadramento técnico com mockup de janela de navegador e capturas reais das aplicações em produção.
  * Modal detalhado de inspeção com métricas de impacto e links diretos para a aplicação viva e código-fonte.
* **Perfil & Trajetória (`02 // PERFIL`)**:
  * Histórico profissional (OTMA Publicidade: 9 anos de rigor técnico e gestão de requisitos).
  * Formação acadêmica (IFTM Campus Uberaba - ADS).
  * Matriz técnica de competências com indicadores de precisão.
  * Download direto do currículo oficial em PDF.
* **Terminal de Contato**:
  * Cópia com um clique de e-mail e telefone/WhatsApp.
  * Links diretos para GitHub, LinkedIn e WhatsApp.

## 🚀 Como Executar Localmente

```bash
# 1. Clone o repositório
git clone https://github.com/vitor0ferreira/personal-portfolio.git

# 2. Acesse a pasta do projeto
cd personal-portfolio

# 3. Instale as dependências
npm install

# 4. Inicie o servidor de desenvolvimento
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no seu navegador.
